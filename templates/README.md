# tack templates (DE/EN) — v0.8.1-dev

Recommended layout: place this `templates/` directory next to your `src/` directory in the repository root. `tack init` can create this folder for new projects.

## Deutsch

Empfohlenes Layout: Lege den Ordner `templates/` neben den Ordner `src/` im Repo-Root ab. `tack init` kann diesen Ordner für neue Projekte anlegen.

### Empfohlenes Standard-Template

`tack_template_min.html` ist das empfohlene Standard-Template. Es bleibt CSS-first, offline-fähig und enthält den Platzhalter `{{TACK_HEADER_TOOLS_HTML}}`, damit die optionale Header-Suche sichtbar werden kann.

```ini
[doc]
template = templates/tack_template_min.html
css      = templates/tack_doc.css
; allow_js_search = no

[bom]
template = templates/tack_template_min.html
css      = templates/tack_doc.css
```

### Optionale native Suche

Eine Suche über mehrere Seiten kann optional über `tack doc` selbst erzeugt werden:

```ini
[doc]
allow_js_search = yes
```

Leitplanken:
- Der Default bleibt ohne JavaScript.
- Die Suche ist Progressive Enhancement; ohne JavaScript bleiben Index, Navigation und Browser-Suche nutzbar.
- Das Template muss `{{TACK_HEADER_TOOLS_HTML}}` ausgeben, wenn das Suchfeld in der Kopfzeile erscheinen soll.
- Die Suchdaten werden statisch aus den bekannten generierten Dokumentseiten erzeugt.

### Legacy-/Beispiel-Template mit Inline-Suche

`tack_template_search_inline.html` bleibt als Beispiel erhalten. Es filtert Navigationslinks und findet Überschriften auf der aktuellen Seite, ist aber nicht der empfohlene Standard für die 0.8.1-dev-Dokumentation.

Die mitgelieferte `tack_doc.css` enthält Grundunterstützung für `prefers-color-scheme`, `prefers-contrast: more` und `forced-colors: active`, damit DOC/BOM-Ausgaben in Hell/Dunkel/High-Contrast ohne JavaScript besser lesbar bleiben.

## English

Recommended layout: place the `templates/` directory next to `src/` in the repository root. `tack init` can create this directory for new projects.

### Recommended default template

`tack_template_min.html` is the recommended default template. It stays CSS-first, offline-friendly, and includes the `{{TACK_HEADER_TOOLS_HTML}}` placeholder so the optional header search can become visible.

```ini
[doc]
template = templates/tack_template_min.html
css      = templates/tack_doc.css
; allow_js_search = no

[bom]
template = templates/tack_template_min.html
css      = templates/tack_doc.css
```

### Optional native search

Cross-page search can optionally be generated by `tack doc` itself:

```ini
[doc]
allow_js_search = yes
```

Guardrails:
- The default stays without JavaScript.
- Search is progressive enhancement; without JavaScript, index, navigation, and browser search remain usable.
- The template must emit `{{TACK_HEADER_TOOLS_HTML}}` if the search field should appear in the header.
- Search data is generated statically from the known generated documentation pages.

### Legacy/example template with inline search

`tack_template_search_inline.html` remains available as an example. It filters navigation links and finds headings on the current page, but it is not the recommended default for the 0.8.1-dev documentation.

The shipped `tack_doc.css` includes baseline support for `prefers-color-scheme`, `prefers-contrast: more`, and `forced-colors: active` so DOC/BOM output remains readable in light/dark/high-contrast setups without JavaScript.
