`fmt_exec_cmd` already tokenizes configured arguments independently, but the
Windows CRT `_spawnvp` call reinterprets space-containing **unquoted**
arguments. RC0.4 quotes and escapes *only formatter subprocess arguments*
for `_spawnvp`. It does not alter the generic build spawning pipeline.
