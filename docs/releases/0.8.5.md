# tack v0.8.5 — Release-Abnahme / Release acceptance

**Datum / Date:** 2026-11-17





**Status:** Finaler lokaler Release-Kandidat. Windows-/Linux-Coverage-Anhebung vom Owner freigegeben; **GitHub-Push, Merge, Tag und GitHub Release noch nicht freigegeben und nicht ausgeführt.**

**Source basis:** RC0.7. Kein weiterer produktiver C89-Codewechsel gegenüber RC0.7.

## Deutsch

### Umfang

- `[fmt]` und `[fmt "NAME"]` werden unabhängig vom `[sbom]`-INI-Parser verarbeitet; strikte Negativtests und Test-Ratchet bleiben aktiv.
- Externe Formatter bleiben optional. Unter Windows werden Formatter-Kindprozesse ohne Shell über den begrenzten `CreateProcessA`-Pfad gestartet. Korrekte Windows-Argumentquotierung und NUL-Terminierung der substituierten Platzhalter sind per Regression getestet.
- `TACK_VERSION` und ausgelieferte `tack.ini` stimmen mit `0.8.5` überein. README, FAQ, Changelog, Roadmap, Release Notes und INI-Referenzen sind DE/EN dokumentiert.
- Keine neuen Build-Abhängigkeiten, keine Tests abgeschwächt, kein HWM abgesenkt. Die 90-%-Initiative für 0.8.6 bleibt getrennt.

## English

The v0.8.5 final local candidate retains strict ISO C89, tack-only builds and optional external formatters. The formatter INI parser is independent from SBOM; Windows formatter child execution uses the shell-free bounded `CreateProcessA` path, with regression coverage for argument quoting and placeholder NUL termination. The canonical binary version is 0.8.5; release documentation is aligned in German and English.

Owner-observed Windows RC0.7 validation passed GCC release (25 PASS/1 SKIP), TinyCC debug (24 PASS/2 SKIP), strict documentation, test ratchet and external `clang-format 23.1.5` E2E including spaces (exit codes 0/2/0/0/1/0). The owner approved the independent increased HWM records: Windows 3577/5906 and Linux 3505/5710. Linux CLI acceptance/check passed on the clean RC0.7 reference checkout. **Windows must rerun both `coverage check` and the instrumented coverage suite after receiving the updated baseline; Windows acceptance PASS is not yet claimed.** No GitHub publication, merge, or tag is authorized or performed.

Historical candidates remain archived, not erased. The 0.8.6 coverage initiative is explicitly out of scope.
