### Accepted coverage high-water mark

The reference measurement for the **Windows-HWM-ready** 0.8.4 source uses Linux GCC 14.2.0 / gcov 14.2.0 (`linux-gcc-14.2.0-gcov-14.2.0-coverage-v1`), covers production `src/` and `include/` excluding `include/tests/`, and merges duplicate source lines across translation units. It was freshly measured, explicitly accepted by the owner using `tack coverage accept --owner-approve` and verified through `tack coverage check`. **Measured and accepted HWM: 3,228/5,708 executable production lines = 56.55221% line coverage.** `coverage/hwm-linux.txt` additionally retains `sources_hash=39ea236e`, `source_state=fd4fe5e6`, `tests_state=9aae154d`, and `flags_state=36eb9e95`. No Windows baseline is fabricated. The backwards-compatible `[coverage] id_windows` key allows Windows to maintain a distinct profile without replacing the Linux ID. The production-code change requires revalidating the Linux HWM, and the Windows measurement/owner approval are pending. **Do not push the GitHub release before acceptance.**
