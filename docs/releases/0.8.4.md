### Accepted coverage high-water mark

The reference measurement for the **final** 0.8.4 source uses Linux GCC 14.2.0 / gcov 14.2.0 (`linux-gcc-14.2.0-gcov-14.2.0-coverage-v1`), covers production `src/` and `include/` excluding `include/tests/`, and merges duplicate source lines across translation units. It was freshly measured, explicitly accepted by the owner using `tack coverage accept --owner-approve` and verified through `tack coverage check`. **Measured and accepted HWM: 3,171/5,651 executable production lines = 56.11396% line coverage.** `coverage/hwm-linux.txt` additionally retains `sources_hash=39ea236e`, `source_state=35a8dea5`, `tests_state=7bbfacc4`, and `flags_state=36eb9e95`. No Windows baseline is fabricated.

**Release process:** Validate the complete source archive; version source/docs/baseline, not `build/`, `.tack-cache/` or `coverage/current.txt`; create the Git commit, attach evidence, then tag `v0.8.4` and publish the GitHub Release. The group-wide BA-STD-C89 draft remains unratified.
