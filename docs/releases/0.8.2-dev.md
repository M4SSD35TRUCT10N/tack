# tack 0.8.2-dev — Compiler je Targetprofil / Compiler by target profile

**Status:** Implementierungskandidat / implementation candidate; NICHT FREIGEGEBEN / NOT RELEASED.

## Deutsch

`[target "NAME".debug]` und `[target "NAME".release]` akzeptieren `compiler` und `compiler_policy`. Priorität: `TACK_CC`, aktives Targetprofil, `[project]`, eingebauter Default. `tack test` nutzt den Compiler und die Extra-`cflags` des gewählten Zielprofils. `tack doctor release --target NAME` zeigt die Auswahl. Der Scope bleibt Build/Toolchain, nicht Agentenorchestrierung.

**Historischer Stand 0.8.2:** Quellsichtung und GCC/C89-Syntaxprüfung, aber keine ausgeführten Regressionstests und keine Windows/TinyCC/TDM-GCC-Matrix. Die Regression `tests/compiler_target_profile_selection_test.c` wurde erst später im Rahmen der 0.8.3-Korrekturen auf Linux/GCC ausgeführt. Compilerwechsel im selben Profil benötigen vor einer Cache-Verbesserung `--rebuild`.

### Offene Abnahmeprüfungen

- Windows/TinyCC: `tack --config .\tack.ini test debug --ci --rebuild -j 1`.
- Windows/GCC: `tack --config .\tack.ini test release --ci --rebuild -j 1`.
- Compiler-Matrix (einschließlich TDM-GCC, GCC und Clang, soweit gefordert) und eigenständige Owner-Freigabe.
- Keine Release- oder Tag-Freigabe ohne belegte Tests.

## English

`[target "NAME".debug]` and `[target "NAME".release]` accept `compiler` and `compiler_policy`. Precedence: `TACK_CC`, active target profile, `[project]`, built-in default. `tack test` uses the selected profile compiler and extra `cflags`. `tack doctor release --target NAME` reports the selection. Scope remains build/toolchain work, not agent orchestration.

**Historical 0.8.2 state:** Source inspection and GCC/C89 syntax checking were completed, but regression tests and the Windows/TinyCC/TDM-GCC matrix were not run. The `tests/compiler_target_profile_selection_test.c` regression ran later under Linux/GCC during the 0.8.3 correction. Switching compilers within the same profile requires `--rebuild` until the cache identity is extended.

### Open acceptance checks

- Windows/TinyCC: `tack --config .\tack.ini test debug --ci --rebuild -j 1`.
- Windows/GCC: `tack --config .\tack.ini test release --ci --rebuild -j 1`.
- Compiler matrix (including TDM-GCC, GCC and Clang as applicable) and independent owner approval.
- No release or tag acceptance without test evidence.
