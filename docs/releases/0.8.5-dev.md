## English

- README introduces the v0.8.2-dev per-profile compiler/policy split prominently, rather than burying it in historical release notes.
- New bilingual [practical walkthrough](../guides/tack-ini.md) and parser-derived [complete reference](../reference/tack-ini.md).
- Fixes the previously unreachable `[fmt]`/`[fmt "NAME"]` INI parser branches; adds a strict C89 regression covering parsed keys, `fmt --list --strict`, spaces in file paths and malformed configurations. `check_cmd`, `diff_cmd`, `env.*` and `fail_fast=no` are still not fully operational.
- The fix contract is recorded in [SPEC 0012](../specs/0012-fmt-ini-parser-separation.md). Separate [0.8.6 coverage plan](../plans/0.8.6-coverage.md) distinguishes line, branch and requirements coverage under independent Windows/Linux measurement profiles.
- Changed: C89 production parser, new C89 test and versioned test inventory; owner-accepted HWMs and `tack.ini` remain unchanged, with no new dependencies or weakened tests.
- Linux GCC release: 26 compiled, 25 PASS, one platform SKIP; Linux GCC/gcov candidate: 3470/5708 (60.79187%), improved but BLOCKED pending HWM acceptance. Windows and external formatter end-to-end tests: NOT RUN. Release promotion requires fresh Linux/Windows gates and version consistency.
