## Deutsch

Die Repositorystruktur verwendet `AGENTS.md` als kanonischen Agentenvertrag, `CLAUDE.md` als Verweis, ausführliche Spezifikationen unter `docs/` und `include/tests/tack_test_embed.h` als einzigen gemeinsamen Testheader (die veraltete Kopie unter `tests/` wurde entfernt). Die Compiler-Feature-Änderung stammt aus v0.8.2-dev; `tack.ini` definiert TinyCC für Entwicklung und GCC für Release. Die Source-Struktur wurde nicht zugunsten zusätzlicher Buildwerkzeuge aufgeweicht.

**Korrektur:** `functional_smoke_test.c` und `help_doctor_output_test.c` waren nach Signaturänderungen nicht aktualisiert. Die Aufrufe wurden angepasst; `fileno()` wird in den beiden betreffenden POSIX-Tests für striktes C89 explizit deklariert. `tack init` erzeugt weiterhin einen minimalen generischen Scaffold mit optionalen Compilerprofil-Beispielen, `tack new` verwendet denselben Init-Pfad. Die DE/EN-Abschnitte wurden wieder aufgeteilt.

**Prüfnachweise:** Linux/GCC und Linux/Clang bestanden jeweils Debug und Release mit 24 Tests; die neue Dokumentationsvertragsprüfung ist enthalten. Der Windows-spezifische Testpfad wurde auf Linux naturgemäß nicht ausgeführt. Windows (nach Owner-Fehler), TinyCC, die vollständige Compiler-Matrix und das Coverage-High-Water-Gate sind noch offen. Release- und BA-STD-C89-Freigabe stehen aus.

## English

The repository uses `AGENTS.md` as its canonical agent contract, `CLAUDE.md` as a pointer, detailed specifications under `docs/`, and `include/tests/tack_test_embed.h` as the sole shared test header (the obsolete copy under `tests/` was removed). Compiler features originated in v0.8.2-dev; `tack.ini` selects TinyCC for development and GCC for release. No extra build systems have been introduced.

**Correction:** `functional_smoke_test.c` and `help_doctor_output_test.c` had stale call signatures. Calls were updated; `fileno()` is explicitly declared in two POSIX tests for strict C89. `tack init` still creates a minimal generic scaffold with optional compiler profile examples, and `tack new` reuses the init path. DE/EN sections were separated again.

**Evidence:** Linux/GCC and Linux/Clang each passed debug and release with 24 tests, including the new documentation contract check. Windows-only test paths could not be executed on Linux. Windows (following the owner's earlier failure), TinyCC, the full compiler matrix and coverage high-water gate remain open. Release and BA-STD-C89 acceptance are pending.
