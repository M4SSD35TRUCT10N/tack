# Entwicklungsauftrag / Development task template

## Deutsch

Für jeden Auftrag dokumentieren: Zielversion und Milestone, konkrete Dateien, Nicht-Ziele, relevante SPEC/ADR, Sicherheits- und Eingabegrenzen, tatsächlich gelesene Dateien, erwartete Regressionstests und Coverage-Gate, Freigabe zur Testausführung, vollständiges ZIP, SHA-256, Commit-Nachricht und Sign-off. Für jedes Gate PASS/FAIL/NOT RUN aufführen. Die Owner-Abnahme ist separat.

Ein Agent stoppt bei fehlender Berechtigung für Scope-, Lizenz- oder Sicherheitsänderungen. Keine erfundenen Prüfergebnisse; keine stillen Änderungen an akzeptierten Test- und Coverage-Baselines.

## English

For each task document: target version and milestone, explicit files and non-goals, relevant SPEC/ADR, security and input boundaries, sources actually read, expected regression tests and coverage gate, permission to execute tests, complete ZIP, SHA-256, commit message and sign-off. Record PASS/FAIL/NOT RUN per gate. Owner acceptance is separate.

An agent must stop if scope, licensing or security changes lack authorization. No fabricated evidence or silent changes to accepted test/coverage baselines.
